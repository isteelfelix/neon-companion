# 09_Roadmap.md

## Фазы развития

### M0 — Базовый MVP
- Текстовой чат
- Подключение OpenAI-совместимых API
- Смена 2D аватаров
- Сохранение истории

### M1 — Улучшенный опыт
- Несколько аватаров с базовой анимацией
- Улучшенный UI
- Поддержка нескольких провайдеров одновременно

### M2 — Голос и 3D
- Голосовой ввод/вывод
- Базовый lipsync
- Переход на 3D аватары

### M3 — VR и расширения
- Поддержка VR (Quest, PCVR)
- Кастомизация аватаров
- Плагины и расширения

### M4 — Полировка и распространение
- Публикация в itch.io / GitHub Releases
- Документация для контрибьюторов
- Донат-система
