# 02_Features_MVP.md

## MVP Scope (первая версия)

### Обязательные функции
- Подключение к одному или нескольким OpenAI-совместимым провайдерам
- Простой чат с агентом
- Смена 2D аватара (несколько предустановленных + возможность загрузки своей картинки)
- Анимация аватаров через sprite-sheet motion packs с фиксированным MVP action set: `idle`, `thinking`, `talking`, `listening`, `smile`, `confused`
- Continuous states + one-shot reactions для 2D baseline
- Сохранение истории чата
- Базовые настройки (API ключ, модель, температура)
- Автоматическое определение доступных моделей через `/models` эндпоинт с кэшированием
- Переключение модели прямо из окна чата (модель-пикер в topbar)
- Многострочный ввод сообщений (auto vertical scroller)
- Масштабируемый рельс сайдбара (160–400px, drag resize)
- NeonDropdown — кастомный выпадающий компонент, заменяет стандартный DropdownField
- Режимы отображения аватара: Static, Animated, Volume3D

### Не входит в MVP
- Голос как обязательный baseline
- 3D realtime модели как обязательный baseline
- Runtime video generation как обязательная зависимость клиента
- VR
- Сложная система памяти агента
- Мультиагентный режим

## Приоритетные задачи
1. Система конфигурации провайдеров
2. Базовый UI чата
3. Система аватаров (2D sprite-sheet baseline для weak PC/mobile)
4. Локальное сохранение данных
5. Кросс-платформенные сборки (Windows + Android)
