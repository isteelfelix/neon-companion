# 05_UI_Flows.md

## Основные экраны MVP

### 1. Главный экран (Chat)
- Окно чата
- Многострочный ввод сообщений (auto vertical scroller)
- Модель-пикер в topbar (`NeonDropdown`) — выбор модели для текущей сессии
- Overlay-диалог выбора модели со скроллируемым списком
- Отображение аватара агента
- Avatar player переключает continuous states: `idle`, `thinking`, `talking`, `listening`
- One-shot reactions: `smile`, `confused`
- Кнопка смены аватара / провайдера
- Масштабируемый рельс сайдбара (`_railResizeHandle`, 160–400px)

### 2. Настройки
- Список подключённых провайдеров
- Добавление/редактирование провайдера
- Общие настройки приложения

### 3. Галерея аватаров
- Табы по режимам: static / animated / 3D
- Просмотр доступных аватаров с переключением `AvatarViewMode` (Static, Animated, Volume3D)
- Загрузка нового аватара
- Предпросмотр action set текущего аватара

## Навигация
Простая навигация через боковое меню или нижнюю панель (в зависимости от платформы).
