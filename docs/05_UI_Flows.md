# 05_UI_Flows.md

## Основные экраны MVP

### 1. Главный экран (Chat)
- Окно чата
- Поле ввода сообщения
- Отображение аватара агента
- Avatar player переключает continuous states: `idle`, `thinking`, `talking`, `listening`
- One-shot reactions: `smile`, `confused`
- Кнопка смены аватара / провайдера

### 2. Настройки
- Список подключённых провайдеров
- Добавление/редактирование провайдера
- Общие настройки приложения

### 3. Галерея аватаров
- Просмотр доступных аватаров (статичные + анимированные sprite-sheet motion packs)
- Загрузка нового аватара
- Предпросмотр action set текущего аватара

## Навигация
Простая навигация через боковое меню или нижнюю панель (в зависимости от платформы).
