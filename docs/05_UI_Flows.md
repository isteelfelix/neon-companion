# 05_UI_Flows.md

## Основные экраны MVP

### 1. Главный экран (Chat)
- Окно чата
- Поле ввода сообщения
- Отображение аватара агента
- Кнопка смены аватара / провайдера

### 2. Настройки
- Список подключённых провайдеров
- Добавление/редактирование провайдера
- Общие настройки приложения

### 3. Галерея аватаров
- Просмотр доступных аватаров (статичные + анимированные спрайтшиты)
- Загрузка нового аватара
- Предпросмотр анимаций

## Навигация
Простая навигация через боковое меню или нижнюю панель (в зависимости от платформы).
