# 00_Overview.md

## Контекст
Приложение `neon-companion` — это Unity-клиент для общения с AI-агентами. Основная цель — дать возможность подключать своих агентов (Hermes, Grok, Claude, локальные модели) и визуализировать их в виде аватара.

## Цели
- Создать удобный клиент для разработчиков
- Поддержка нескольких AI-провайдеров
- Визуализация агентов (2D спрайтшиты → 3D → VR)
- Открытый код + донаты как модель монетизации

## Нефункциональные требования
- Кросс-платформенность (Windows, Linux, Android, iOS)
- Простота подключения новых API
- Чистая и расширяемая архитектура
- Хорошая производительность на мобильных устройствах

## Глоссарий
- **Аватар** — визуальное представление агента (2D/3D модель)
- **Провайдер** — источник AI (Hermes, OpenAI, Grok и т.д.)
- **Компаньон** — режим, при котором агент ведёт себя как постоянный собеседник

## Целевая аудитория
Разработчики и технически подкованные пользователи, которые хотят иметь своего AI-компаньона с визуальной составляющей.
