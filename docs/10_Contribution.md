# 10_Contribution.md

## Как внести вклад

1. Сделай форк репозитория
2. Создай отдельную ветку под свою фичу
3. Следуй код-стайлу проекта
4. Открой Pull Request

## Код-стайл
- Используй PascalCase для публичных классов и методов
- Приватные поля — camelCase с `_`
- Комментарии на русском (для сложной логики)

## Правила
- Не ломай существующий функционал MVP
- Добавляй тесты, где это возможно
- Обновляй документацию при добавлении новых фич
