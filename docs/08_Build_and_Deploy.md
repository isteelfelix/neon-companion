# 08_Build_and_Deploy.md

## Сборка проекта

### Требования
- Unity 2022.3 LTS или новее
- Android SDK (для мобильных сборок)
- Git

### Процесс сборки
1. Открыть проект в Unity
2. Перейти в `File → Build Settings`
3. Выбрать целевую платформу
4. Собрать

## CI/CD (будущее)
Планируется настроить GitHub Actions для автоматической сборки под Windows и Android.
