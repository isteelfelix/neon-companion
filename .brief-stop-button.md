# Add Stop Button to Chat — Cancel In-Progress Generation

## Goal
Add a stop button to the chat UI that cancels the current streaming response. Critical for local LLMs that can loop endlessly with no way to interrupt.

## Files to Modify
1. `Assets/UI/Chat/ChatView.uxml` — add stop button
2. `Assets/Scripts/Runtime/UI/UITK/ChatController.cs` — wire stop button, toggle visibility
3. `Assets/Scripts/Runtime/UI/Chat/ChatViewModel.cs` — add CancelGeneration method
4. `Assets/Scripts/Runtime/Chat/ChatService.cs` — expose CancelGeneration on current ViewModel

## Critical Constraints
- C# 9 only — Unity 2022.3
- The CTS in ChatViewModel is a single instance — after cancel, it must be recreated for future requests
- Stop button should only be visible during active streaming
- After cancel, the partial response should be kept (not deleted) — the user sees what was generated before cancel

## Task 1: ChatViewModel.cs — Add CancelGeneration

Add a public method to cancel the current request:

```csharp
public void CancelGeneration()
{
    _cts.Cancel();
}
```

After cancellation, the CTS is spent. It needs to be recreated. Add a helper:

```csharp
private CancellationTokenSource _cts = new CancellationTokenSource();

public CancellationToken CancellationToken => _cts.Token;

public void CancelGeneration()
{
    _cts.Cancel();
    _cts.Dispose();
    _cts = new CancellationTokenSource();
}
```

Replace the field initialization on line 16 and update all references from `_cts.Token` to `CancellationToken` property.

## Task 2: ChatService.cs — Expose Cancel

Add a method to ChatService that delegates to the current ViewModel:

```csharp
public void CancelCurrentGeneration()
{
    _currentChatViewModel?.CancelGeneration();
}
```

Place it near the other public methods (around line 226-240).
